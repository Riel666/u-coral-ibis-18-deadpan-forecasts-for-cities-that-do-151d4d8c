## What it does

`main.ts` writes a single line — the deadpan one-line weather forecast for a city that does not exist — to `/output/entry.txt`. The program is fully deterministic: no
randomness, no network, no input. It always writes exactly the same line.

> Glimmerwick: sideways rain tonight, 40% chance of one confused pelican. High 12°, low: why. Umbrellas optional; dignity not included.

## Run

Requires Node 22.18 or later (the grader runs Node 22.23.4):

```sh
node main.ts
cat /output/entry.txt
```
